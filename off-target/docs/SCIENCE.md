# OFF TARGET. — Science notes

The game is fiction inspired by CRISPR genome editing and anti-CRISPR proteins. It deliberately keeps science
words out of play. The ending (`src/content/science.ts`) shows the explanatory pages.

## Status

- The explanatory text of the ending is a **placeholder**, to be written with the contributing scientist and
  checked by a reviewer. The game displays whatever is in `src/content/science.ts`.
- Character inspirations in `src/content/characters.ts` marked **REVIEW** need scientific sign-off. SNIP and
  FREEZE are fictional and not assigned to any real protein.
- Countdowns, stages, compatibility rules, power-ups and scores are gameplay fiction, not kinetics.
