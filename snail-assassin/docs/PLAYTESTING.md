# Playtesting — Snail Assassin

## How to run a session

1. Build or run the current version (`npm run dev`, or share a `dist/` build).
2. Give testers **no instructions** beyond "play however you like". Watch silently.
3. Note where they hesitate, misunderstand, or smile.
4. Ask the debrief questions, then log results below.

## Debrief questions

- What do you think you were doing? What was the goal?
- What was the most fun / most frustrating moment?
- Did anything feel unfair or confusing?
- (After the epilogue) What did you learn about cone snails? Did that feel like a lesson or part of the game?

## Accessibility checks per session

Keyboard-only · touch-only · sound off · colour-blind simulation · reduced motion · small screen (iPad)
