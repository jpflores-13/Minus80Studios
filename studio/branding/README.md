# Branding

Placeholder home for the -80 Studio identity.

| Folder        | Contents                                                               |
| ------------- | ---------------------------------------------------------------------- |
| `logos/`      | Logo files (SVG master + PNG exports)                                  |
| `typography/` | Font choices and licenses (only fonts licensed for web/game embedding) |
| `palettes/`   | Studio palette and per-game palettes                                   |
| `guidelines/` | Voice, tone, and usage rules                                           |

## Working identity (draft)

- **Name:** -80 Studio, always written with a plain hyphen: "-80" (never spelled "Minus").
- **Tagline:** _Inspired by real discoveries._
- **Voice:** curious, confident, playful. Never preachy. Science is the twist, not the lecture.

Log every external font or image (with its license) here before use.
